# Minimax H3 Workspace (Uncensored Edition)

Бесплатное приложение для Windows: локальная генерация видео моделью **MiniMax H3** без цензуры и без знания ComfyUI.
ComfyUI работает внутри, невидимо для пользователя. Видно только простые формы, прогресс, живое превью и библиотеку готовых видео.

> Форк официального проекта [Yuliya1310/minimax-h3-workspace](https://github.com/Yuliya1310/minimax-h3-workspace), расширенный поддержкой **Uncensored LLM-моделей**, **каталогов Civitai и Hugging Face**, **пользовательских LoRA**, умным детектором конфликтов, улучшенным определением локальных дисков и автономными обновлениями.

## Что нового в версии 1.1.9 (Синхронизация с upstream + Uncensored):

1. **Длинное видео (Long Video) и склейка сцен (Монтаж):**
   - Генерация длинных роликов из нескольких связанных сцен (до 12 сцен подряд) со связыванием через хвостовой латентный кадр (`tail latent continuation`).
   - Каждая сцена плавно перетекает в следующую без швов и разрывов.
   - Встроенный монтаж сцен в готовый фильм с наложением фоновой музыки или с сохранением генеративного звука MiniMax H3.
   - Сохранение и возобновление проектов длинных видео (`state_{k}.latent`) даже после перезапуска приложения.

2. **Ускорение Turbo-SLA (Быстрый черновик):**
   - Новый режим ускорения в Image-to-Video: генерация в 1.3 раза быстрее для слабых видеокарт при минимальной потере резкости.

3. **Бесшовное зацикливание видео (Loop / Живые обои):**
   - Опция создания бесконечных циклов: ролик идеально заканчивается тем же кадром, с которого начался.

4. **Новые режимы Агента и Скиллы:**
   - **Storyboard (Раскадровка)**: скилл планирования и генерации серий кадров под управлением FLUX.2 Klein.
   - **FLUX.2 Klein**: быстрый и качественный генератор референсов и раскадровок.
   - **Лист персонажа (6 панелей)**: расширенный генератор характер-листов со всех ракурсов (фас, профиль, 3/4, эмоции, детали).

5. **Зеркала Hugging Face и повышенная стабильность:**
   - Поддержка зеркал Hugging Face для загрузки весов на нестабильных интернет-каналах.
   - Увеличение числа попыток докачки моделей до 40 с автопродолжением из `.part`-файлов.
   - Автоматическая очистка осиротевших процессов ComfyUI при сбоях и корректное предупреждение при отсутствии Microsoft Edge WebView2.

## Особенности Uncensored Edition

1. **Безцензурная модель Агента (Gemma 4 12B Heretic):**
   - Интегрирована модель **Gemma 4 12B (Uncensored Heretic)** ([llmfan46/gemma-4-12B-it-qat-q4_0-uncensored-heretic-GGUF](https://huggingface.co/llmfan46/gemma-4-12B-it-qat-q4_0-uncensored-heretic-GGUF)).
   - Сняты ограничения и моральные фильтры при генерации сценариев, диалогов персонажей и креативных промптов.
   - Имеется бесшовный fallback на стандартную Gemma 4 при отсутствии файлов heretic на диске.

2. **Двойной каталог LoRA (Civitai + Hugging Face) и скачивание в один клик:**
   - Прямо в интерфейсе доступен объединенный каталог моделей с двух ключевых площадок:
     - **Civitai** (с поддержкой зеркала `civitai.red` без блокировок в РФ и `civitai.com`).
     - **Hugging Face (`huggingface.co`)** с поиском по репозиториям и файлам `.safetensors`.
   - Поддержка закрытых / gated / 18+ моделей через Civitai API Key и Hugging Face Access Token.
   - Поддержка живых видео-превью `.mp4`, прямые ссылки на страницу моделей, автосохранение триггеров и описаний.
   - Прямая загрузка по URL ссылке (Civitai или Hugging Face).

3. **Полноценная поддержка пользовательских LoRA и интеграция с Агентом:**
   - **Человекопонятные названия и описания**: вместо непонятных технических имён файлов (вроде `H3_DR34ML4Y_P1.safetensors`, `latexClothesMinimax_v1.safetensors`, `h3-realism-people.safetensors` и др.) отображаются понятные названия («DR34ML4Y NSFW Позы & Секс», «Латексная одежда», «Реализм людей»), категории и подсказки о назначении.
   - **Умный Агент с автоподстановкой триггерных слов**: Агент (Gemma 4 Heretic) автоматически видит все включенные LoRA и их назначение. При составлении промпта Агент сам органично вставляет ключевые триггеры (`m15510n4ry`, `d0gg1e`, `latex`, `nude`, `realism` и т.д.) в описание сцены.
   - **Интерактивные триггеры в один клик**: триггерные слова отображаются в виде интерактивных бейджей прямо в карточке LoRA — кликните на триггер, и он скопируется в буфер обмена.
   - **Умный анализатор конфликтов LoRA (Conflict Detector)**: система в реальном времени анализирует список активных моделей и предупреждает прямо в интерфейсе о несовместимости:
     - *Раздвоение лица и губ*: предупреждает об активации моделей шпагатов / деления планов (`splits-os`), которые на портретах разрывают геометрию рта и подбородка.
     - *Конфликт планировщиков*: выявляет одновременную работу нескольких Турбо-LoRA (4 шага vs 8 шагов), ломающих диффузию и приводящих к черным кадрам или сплошному шуму.
     - *Конфликт динамики*: предупреждает при одновременном включении форсированного ускорения (`Speed Slider`) и сглаживания (`Motion Repair`).
     - *Перегруз суммарного веса (Overbaking)*: сообщает о превышении суммарной силы (> 1.2–1.3), из-за которого кожа становится восковой, а черты лица плавятся.
     - *Наложение анатомических моделей*: предотвращает артефакты при одновременной работе нескольких тяжелых NSFW LoRA.
     - *Кнопки быстрого исправления*: в один клик отключает конфликтующую LoRA или снижает веса до безопасных значений.
   - **Редактирование параметров LoRA**: для любой вашей собственной LoRA можно в один клик задать своё понятное имя, описание и список триггеров.
   - **Единое управление LoRA во всех режимах генерации**: гибкая настройка веса и включение/выключение прямо из разделов:
     - **Image-to-Video**
     - **Lipsync / клип**
     - **Референсы**
     - **Актёрская игра**
     - **Экшн-сцены**
     - **Длинное видео**

4. **Удобный чат Агента:**
   - **Быстрое копирование запросов**: добавлены кнопки `📋 Копировать` и `✏ В поле ввода` для каждого вашего предыдущего сообщения в чате. Теперь легко повторить или доработать запрос в один клик.
   - **Свободное выделение текста мышью** для цитирования и копирования фрагментов.

5. **Автоопределение существующих папок:**
   - Алгоритм поиска автоматически находит существующую рабочую директорию ComfyUI и модели на любых дисках (например, `G:\MinimaxH3Workspace`, `D:\MinimaxH3Workspace` и др.).
   - При установке инсталлятор не затирает ваши скачанные 100+ ГБ моделей.

6. **Автономная система обновлений:**
   - Модуль обновлений настроен на данный репозиторий (`mrtek/minimax-h3-workspace-uncensored`).
   - Исключена случайная перезапись вашей сборки официальным цензурированным релизом.

7. **Исправление ошибок оригинального workflow:**
   - Исправлена цепочка внедрения кастомных LoRA в графы генерации видео.
   - Корректная обработка UTF-8 в процессах ComfyUI для работы на русскоязычных Windows.

## Что умеет приложение

- **Image-to-Video** — видео по тексту, по картинке, по первому и последнему кадру, зацикливание и ускорение Turbo-SLA.
- **Длинное видео (Long Video)** — связанная цепочка сцен (до 12) с сохранением преемственности персонажей и локаций, монтаж в единый фильм.
- **Lipsync / клип** — персонаж поёт или говорит под ваше аудио (со встроенным редактором для обрезки аудио).
- **Референсы** — видео по картинкам, референс-видео и аудио; ускорение Pika H3 Flex или стандартное.
- **Актёрская игра** — диалоги и крупные планы: стартовый кадр и образец голоса, новые реплики из промпта.
- **Экшн-сцены** — бой, погоня, бег, динамичное движение.
- **Картинка по тексту** — Krea 2 и FLUX.2 Klein рисуют картинку или серии по описанию.
- **Правка картинки** — Qwen Image 2.1: измените свою картинку словами или соберите лист персонажа (4 или 6 панелей).
- **Улучшение качества видео** — апскейл готового видео в Библиотеке через SeedVR2.
- **Агент** — локальный безцензурный AI-ассистент помогает придумывать сцены и писать промпты по кинематографическим правилам.
- **Очередь и Библиотека** — пакетная генерация, избранное, история, быстрый экспорт.
- **Свои LoRA и Модели** — каталог Civitai и Hugging Face, подключение персонажей, стилей одежды и кастомных весов с контролем конфликтов.

## Установка

1. Перейдите в раздел [**Releases**](https://github.com/mrtek/minimax-h3-workspace-uncensored/releases).
2. Скачайте файл установщика: **`Minimax.H3.Workspace.Uncensored-Setup_v1.1.9.exe`** (или `Minimax.H3.Workspace.Uncensored-Setup.exe`).
3. Запустите его.
4. *Windows SmartScreen может показать предупреждение, так как сборка сообщества не имеет платного сертификата Microsoft — нажмите «Подробнее» → «Выполнить в любом случае».*

> **Требования к системе:**
> - Windows 10/11 64-bit
> - Видеокарта NVIDIA (от 8 ГБ VRAM, рекомендуется 12–16+ ГБ) со свежим драйвером (версия 580+)
> - 32 ГБ оперативной памяти
> - Свободное место на диске: 40–100 ГБ (в зависимости от выбранных моделей)

## Варианты первого запуска

- **«Я новичок — у меня ничего нет»**: приложение само скачает ComfyUI, необходимые ноды и модели.
- **«У меня уже есть ComfyUI и модели»**: укажите существующую папку или подключитесь к уже работающему ComfyUI на `http://127.0.0.1:8188`. Приложение подхватит все модели автоматически.
- **«Только облако»**: режим генерации через RunningHub по вашему API-ключу для компьютеров со слабыми видеокартами.
