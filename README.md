# Minimax H3 Workspace (Uncensored Edition)

Бесплатное приложение для Windows: локальная генерация видео моделью **MiniMax H3** без цензуры и без знания ComfyUI.
ComfyUI работает внутри, невидимо для пользователя. Видно только простые формы, прогресс, живое превью и библиотеку готовых видео.

> Форк официального проекта [Yuliya1310/minimax-h3-workspace](https://github.com/Yuliya1310/minimax-h3-workspace), расширенный поддержкой **Uncensored LLM-моделей**, **каталогов Civitai и Hugging Face**, **пользовательских LoRA**, умным детектором конфликтов, улучшенным определением локальных дисков и автономными обновлениями.

---

## Что умеет приложение

- **Главная** — удобный стартовый экран: быстрый выбор категорий (Изображение, Видео, Увеличить), живые видео-превью для каждого режима, поиск и закрепление в избранное.
- **Image-to-Video** — видео по тексту, по картинке, по первому и последнему кадру, бесшовное зацикливание и ускорение Turbo-SLA.
- **Видеостудия (Длинное видео)** — создание целых фильмов и клипов по сценам (до 12 сцен по 3–15 секунд):
  - *Режим «Новый план» (`new shot`)*: сцена строится заново по референсным изображениям без деградации качества и лиц.
  - *Мягкие звуковые стыки (`audio fade`)*: предотвращение щелчков и резких перепадов громкости между сценами.
  - *Сохранение этапов проекта*: возможность сохранять промежуточные дубли сцен и возвращаться к ним.
  - *Индивидуальные референсы*: персональные картинки для каждой конкретной сцены.
- **Монтаж** — склейка готовых клипов в единый ролик:
  - *Быстрый режим через портативный FFmpeg*: мгновенная склейка без перерендера нейросетью и наложение фоновой музыки с гибким микшированием громкости.
  - *Режим через ComfyUI*: покадровая обрезка длительности клипов (`Video Slice`), наложение кинематографического плёночного зерна (`ImageNoiseAugmentation`) и увеличение отдельных фрагментов (RelayVSR или SeedVR2).
- **Сравнение «До / После» (Before/After Slider)** — интерактивный слайдер в просмотрщике для наглядного сравнения оригинала и увеличенного результата (видео и фото).
- **Lipsync / клип** — персонаж поёт или говорит под ваше аудио (с редактором для обрезки аудио).
- **Референсы** — видео по картинкам, референс-видео и аудио; ускорение Pika H3 Flex (хороший звук) или стандартное.
- **Актёрская игра** — диалоги и крупные планы: стартовый кадр и образец голоса, новые реплики из промпта.
- **Замена персонажа** — загрузите своё видео и картинку героя (до двух), напишите промпт: человека в видео заменит герой с картинки, движения, камера и фон остаются.
- **Экшн-сцены** — бой, погоня, бег, динамичное движение.
- **Изображение по тексту** — на выбор Krea 2 (RedMix/Realism), FLUX.2 klein или Qwen 2.1; серия картинок по списку промптов (до 50 за раз).
- **Правка изображения** — Qwen Image 2.1 (ChatRLabs Uncensored LoRA) или FLUX.2 klein (коммерческая лицензия): изменение изображения словами, лист персонажа (4 или 6 панелей), раскадровка и кнопка «До 2К, мягко» в Библиотеке.
- **Увеличение видео и фото** — два метода: быстро (RelayVSR ×2, только видео) и качественно (SeedVR2 для видео и фото).
- **Агент** — локальный бесплатный AI-режиссёр пишет промпты по киноправилам («Единый мир», смена планов, теги `new`). Выбор модели: Gemma 4 или Qwen3-VL (включая Uncensored Heretic) с историей чатов и автопереводом на русский язык.
- **Очередь и плавающий Док (Dock)** — пакетная генерация, сворачиваемый виджет очереди, готовые результаты сами попадают в Библиотеку.
- **Библиотека** — видео и изображения, избранное, безопасное удаление в Корзину Windows (`SHFileOperationW`), сохранение копий в `\MinimaxH3Workspace\output\`.
- **Свои LoRA и Модели** — встроенный каталог Civitai и Hugging Face, детектор конфликтов LoRA, мгновенный поиск и переключение вариантов весов.
- **Свои workflow и Облачные серверы** — поддержка пользовательских ComfyUI API графов, облачного рендера RunningHub и подключение арендованных серверов Immers.Cloud по API-ключу.

## Установка

1. Перейдите в раздел [**Releases**](https://github.com/mrtek/minimax-h3-workspace-uncensored/releases).
2. Скачайте файл установщика: **`Minimax.H3.Workspace.Uncensored-Setup_v1.1.9.exe`** (или `Minimax.H3.Workspace.Uncensored-Setup.exe`).
3. Запустите его.
4. *Windows SmartScreen может показать предупреждение, так как сборка сообщества не имеет платного сертификата Microsoft — нажмите «Подробнее» → «Выполнить в любом случае».*

> **Требования к системе:**
> - Windows 10/11 64-bit
> - Видеокарта NVIDIA (от 8 ГБ VRAM, рекомендуется 12–16+ ГБ) со свежим драйвером (версия 580+)
> - 32 ГБ оперативной памяти
> - Свободное место на диске: 40–100 ГБ (в зависимости от выбранных моделей)

## Варианты первого запуска

- **«Я новичок — у меня ничего нет»**: приложение само скачает ComfyUI, необходимые ноды и модели.
- **«У меня уже есть ComfyUI и модели»**: укажите существующую папку или подключитесь к уже работающему ComfyUI на `http://127.0.0.1:8188`. Приложение подхватит все модели автоматически.
- **«Только облако»**: режим генерации через RunningHub по вашему API-ключу для компьютеров со слабыми видеокартами.

## Запуск из исходников

```bash
git clone https://github.com/mrtek/minimax-h3-workspace-uncensored.git
cd minimax-h3-workspace-uncensored
pip install aiohttp pywebview
python app/main.py
```

### Сборка установщика
1. `python -m PyInstaller app/build/h3studio.spec --distpath app/build/dist --workpath app/build/work --noconfirm`
2. `"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" app\build\h3studio.iss`
