Модель

Куда скачать помощника. Всё останется только в этой папке, больше нигде.
У меня уже есть модель — указать папку
Папка с моделью в формате .gguf (например Gemma 4 от ggml-org или unsloth). Если рядом лежит файл mmproj…gguf, агент будет видеть картинки. Скачается только движок llama.cpp (37 МБ).
У меня уже есть whisper — указать папку
Папка с программой whisper-cli.exe и/или моделью ggml-….bin (многоязычной, не «.en»). Что найдётся — будет использовано, недостающее приложение скачает отдельно.

    Движок

    Ноды ComfyUI

    Скачайте недостающую ноду по ссылке (кнопка «Code» → «Download ZIP» на GitHub), распакуйте папку в ComfyUI\custom_nodes и перезапустите ComfyUI. Потом нажмите «Проверить ещё раз».

    Свои LoRA · для тех, кто знает ComfyUI

    Положите файл LoRA в папку ComfyUI\models\loras, нажмите «Обновить список» и добавьте её. Она подключится ко всем разделам сразу после основной модели. Новичкам ничего менять не нужно: всё уже готово. Свои VAE и модели меняются кнопкой «Заменить…» в списке ниже.
