Универсальная творческая студия для Windows: локальная генерация видео и графики с помощью нейросетей семейства **MiniMax H3**, **FLUX.2 klein**, **Krea 2**, **Qwen 2.1**, а также быстрый видеомонтаж, локальный AI-режиссёр и расширенная поддержка пользовательских LoRA **без ограничений и цензуры**.

ComfyUI работает автономно «под капотом» программы: пользователю не нужно соединять ноды, настраивать спагетти-графы или разбираться в пайплайнах. Вы получаете чистый, современный русскоязычный интерфейс, живое превью генерации, библиотеку результатов и профессиональные инструменты монтажа.

> **О форке**: Проект основан на официальном репозитории [Yuliya1310/minimax-h3-workspace](https://github.com/Yuliya1310/minimax-h3-workspace) и существенно расширен: интеграция **Uncensored LLM-моделей**, **Студии монтажа на портативном FFmpeg**, **встроенного ComfyUI Updater**, каталогов **Civitai и Hugging Face**, поддержки **Omni-LoRA / ChatRLabs / RedCraft**, аппаратного мониторинга железа и устранения системных зомби-процессов ядра Windows.

## 🌟 Ключевые возможности программы

### 1. Стартовый экран «Главная»
- **Быстрый выбор режимов**: наглядное переключение между категориями (Видео, Изображения, Увеличение, Монтаж).
- **Живые видео-превью**: анимированные превью каждого режима с примерами результатов.
- **Избранное и быстрый поиск**: мгновенный переход к нужным инструментам в один клик.

---

### 2. Генерация видео (Family MiniMax H3)

- **Image-to-Video** — генерация динамического видео высокого качества:
  - Генерация по текстовому промпту или по стартовой картинке.
  - Режим перехода между кадрами (**Первый + Последний кадр**).
  - Бесшовное зацикливание видео (Looping).
  - Аппаратное ускорение **Turbo-SLA** (быстрая генерация с минимальными задержками).
- **Lipsync / клип** — озвучка и анимация речи персонажа:
  - Точная синхронизация губ (Lip Sync) под любую загруженную аудиодорожку (речь, пение).
  - Встроенный интерактивный аудиоредактор с обрезкой фрагментов.
- **Референсы (Singularity Ref2V)** — консистентные видео:
  - Сохранение внешности персонажей, локаций, одежды и стиля из референсных изображений и видео.
  - Выбор режима генерации звука: быстрый Pika H3 Flex или стандартный режим.
- **Актёрская игра** — глубокие диалоги, крупные планы и выразительные эмоции:
  - 10-шаговый пайплайн генерации с сохранением мимики по стартовому кадру и образцу голоса.
  - Генерация новых реплик прямо из текстового описания сцены.
- **Замена персонажа (Face / Character Swap)**:
  - Загрузка исходного видео и изображений одного или двух целевых героев.
  - Нейросеть бережно переносит внешность новых персонажей, сохраняя исходные движения тела, пластику, фон и траекторию камеры.
- **Видеостудия (Мульти-сцены и длинные клипы)**:
  - Пошаговое создание целых фильмов и музыкальных клипов до 12 сцен (от 3 до 15 секунд каждая).
  - **Режим «Новый план» (`new shot`)**: сцена генерируется заново по референсным изображениям без деградации лиц и артефактов накопления ошибки.
  - **Мягкие звуковые стыки (`audio fade`)**: плавные кроссфейды звука без щелчков и перепадов громкости.
  - **Сохранение этапов проекта**: возможность возвращаться к предыдущим дублям и экспериментировать с отдельными сценами.
  - Индивидуальные референсы для каждой отдельной сцены.
- **Экшн-сцены** — драйв, битвы, погони и спорт:
  - Оптимизированный гибридный пайплайн (8+4 шага) для передачи сверхбыстрых движений без смазывания.

### 3. Генерация и правка изображений

- **Изображение по тексту**:
  - Поддержка лучших моделей: **Krea 2** (пресеты RedMix и Realism), **FLUX.2 klein** и **Qwen 2.1**.
  - Пакетная генерация до 50 изображений за раз по списку промптов.
- **Правка изображения (Inpainting & Directing)**:
  - **Qwen Image 2.1** с интеграцией **ChatRLabs Uncensored LoRA** или **FLUX.2 klein**.
  - Правка изображений естественным языком («замени одежду на вечернее платье», «добавь солнцезащитные очки», «измени время суток на закат»).
  - **Лист персонажа (Character Sheet)**: автоматическая генерация героя в 4 или 6 ракурсах для консистентных видео.
  - **Раскадровка**: создание серии кадров сценария для последующей анимации.
  - Мягкий апскейл изображений до 2K прямо из Библиотеки.

---

### 4. Увеличение качества (Upscale) и слайдер «До / После»

- **Два передовых алгоритма апскейла**:
  - **Быстро (RelayVSR ×2)**: аппаратный сверхбыстрый апскейл видео без потери плавности.
  - **Максимальное качество (SeedVR2)**: глубокая детализация лиц, волос, кожи и текстур для видео и фото.
- **Интерактивный слайдер «До / После» (Before/After Slider)**:
  - Полноэкранный просмотрщик со слайдером шторки: наглядное попиксельное сравнение оригинального ролика и увеличенного результата.

---

### 5. Раздел «Монтаж» — Двойная видеостудия

Раздел полностью разделён на два независимых мощных инструмента:

#### А. Монтаж через ComfyUI
- Склейка стандартными нодами ComfyUI.
- Покадровая обрезка длительности клипов (`Video Slice`).
- Наложение кинематографического плёночного зерна (`ImageNoiseAugmentation`).
- Апскейл отдельных клипов перед склейкой.

#### Б. Студия монтажа FFmpeg (Быстрый нелинейный монтаж)
- **Сверхбыстрый рендер (от 2 до 5 секунд)** благодаря встроенной поддержке аппаратного ускорения **NVIDIA NVENC** (`-hwaccel auto`).
- **Синхронизация с Библиотекой и ПК**: клипы добавляются в монтажную ленту кликом из Библиотеки приложения или перетаскиванием с диска.
- **Библиотека видеопереходов (xfade)**: плавное растворение (Crossfade), затемнение (Fade to black), уход в белое (Fade to white), шторки (Wipe Left/Right/Up/Down), скольжение (Slide), вытеснение и др. с точной настройкой длительности перехода.
- **Кадрирование и форматы**:
  - Горизонтальный 16:9 (YouTube, ТВ).
  - Вертикальный 9:16 (Shorts, Reels, TikTok).
  - Широкоформатный 21:9 (Кинематограф).
  - Квадрат 1:1.
  - **Интеллектуальный размытый фон**: при несовпадении пропорций клип центрируется, а поля заполняются гармонично размытым фоном видео без черных полос.
- **Фоновая музыка и звук**: наложение любого аудиофайла (MP3, WAV, AAC, FLAC) с регулировкой громкости фонового трека и оригинального звука клипов.
- **Цветокоррекция и фильтры**: интерактивные ползунки Яркости, Контраста, Насыщенности, а также готовые пресеты (Кино, Нуар, Теплый закат, Холодный sci-fi, Сочный поп).
- **Титры и водяные знаки**: добавление надписей внизу, по центру или вверху с настройкой размера и цвета.
- **Портативный FFmpeg в один клик**: автоматическая установка и проверка обновлений проверенных сборок FFmpeg 9.0+ прямо в рабочую папку программы без необходимости установки стороннего ПО в систему.

### 6. Локальный AI-Режиссёр (Агент)

- **Полностью локальный LLM-движок**: работает на базе оптимизированного `llama-server.exe` (llama.cpp) — не требует интернета и платных API.
- **Мультимодальное зрение**: агент «видит» загруженные картинки и видеокадры с помощью визуального проектора `mmproj`.
- **Выбор моделей режиссуры**:
  - **Gemma 4 12B (Heretic Uncensored)** — творческий генератор промптов без цензуры.
  - **Qwen3-VL** — аналитическая мультимодальная модель для точной раскадровки.
- **Система кинонавыков (Skills)**:
  - Автоматическое составление промптов по правилам кинематографа («Единый мир», смена крупности планов, теги `new shot`).
  - Карточки персонажей и поддержание непрерывности сюжета.
  - Автоматический перевод диалогов и подсказок на русский язык.
- **Вкладки независимых чатов**: ведение разных проектов и сценариев с сохранением истории.
- **Изоляция видеопамяти**: перед вызовом агента VRAM ComfyUI автоматически освобождается, исключая дедлоки и нехватку памяти.

### 7. Менеджер моделей и LoRA без цензуры

- **Встроенный браузер Civitai и Hugging Face**: поиск, просмотр карточек и загрузка пользовательских LoRA под MiniMax H3 в один клик.
- **Каталог проверенных LoRA**:
  - Реализм людей, текстура кожи и волос, анатомия.
  - Динамика движений, ракурсы камеры и кинематографический свет.
  - Интеграция ChatRLabs Omni-LoRA и RedCraft.
- **Интеллектуальный контроль**: автоматическое определение триггерных слов и предотвращение конфликтов весов.

---

### 8. Встроенный ComfyUI Updater

- **Автономное обновление**: автоматическая проверка наличия новых стабильных версий ComfyUI через GitHub API.
- **Обновление в один клик**: программа сама останавливает движок, запускает скрипт обновления через `pygit2`, проверяет целостность и перезапускает ComfyUI, сохраняя все ваши установленные модели и ноды.

---

### 9. Аппаратный мониторинг и стабильность

- **Закреплённый монитор ресурсов**: в левой панели всегда отображается реальное состояние ПК:
  - Статус подключения движка ComfyUI.
  - Название видеокарты и текущая нагрузка GPU (%).
  - Занятая и доступная видеопамять (VRAM).
  - Нагрузка центрального процессора (CPU %).
  - Использование оперативной памяти (RAM).
  - Температура GPU и текущее энергопотребление (Ватт).
  - Свободное место на рабочем диске.
- **Архитектура «Zero-Zombie»**: использование **Windows Job Objects** гарантирует, что при закрытии программы все фоновые подпроцессы (`llama-server.exe`, `whisper.exe`, сокеты ComfyUI) мгновенно завершаются операционной системой без зависаний в Диспетчере задач.
- **Безопасная Библиотека**: удаление медиафайлов производится в системную **Корзину Windows** (`SHFileOperationW`) — случайное удаление ценного дубля можно легко отменить.

## 🚀 Установка и быстрый запуск

### Вариант 1. Готовый установщик (Рекомендуется)

1. Откройте страницу [**Releases на GitHub**](https://github.com/mrtek/minimax-h3-workspace-uncensored/releases).
2. Скачайте последнюю версию инсталлятора: **`Minimax.H3.Workspace.Uncensored-Setup_v1.1.12.exe`**.
3. Запустите установку.
   *(Если Windows SmartScreen выдаст предупреждение о неизвестном издателе, нажмите «Подробнее» → «Выполнить в любом случае»).*
4. Запустите ярлык **Minimax H3 Workspace** на рабочем столе.

При первом старте выберите удобный вариант:
- **«Я новичок — у меня ничего нет»**: программа самостоятельно развернёт портативный ComfyUI, скачает нужные ноды и базовые модели.
- **«У меня уже есть ComfyUI и модели»**: укажите путь к вашей существующей папке или введите адрес работающего ComfyUI (`http://127.0.0.1:8188`) — приложение моментально подхватит все файлы.
- **«Только облако»**: режим генерации через RunningHub или арендованные серверы Immers.Cloud для ноутбуков и слабых видеокарт.

---

### Вариант 2. Запуск из исходного кода

```bash
# Клонирование репозитория
git clone https://github.com/mrtek/minimax-h3-workspace-uncensored.git
cd minimax-h3-workspace-uncensored

# Установка зависимостей Python
pip install aiohttp pywebview

# Запуск приложения
python app/main.py
```

### Сборка EXE-дистрибутива и инсталлятора

Для компиляции автономного установщика используются PyInstaller и Inno Setup:
```powershell
# 1. Сборка Python-приложения
python -m PyInstaller app/build/h3studio.spec --distpath app/build/dist --workpath app/build/work --noconfirm

# 2. Компиляция Inno Setup инсталлятора
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" app/build/h3studio.iss
```
Готовый файл инсталлятора будет создан в папке `app/build/output/`.
